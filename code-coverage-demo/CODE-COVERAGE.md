# Code Coverage Documentation

This project uses a custom Gradle plugin located in `buildSrc` to manage code coverage reporting for a multi-module Java project. It provides both standard aggregate coverage reports and diff-based coverage reports.

## Overview

The code coverage setup is implemented in `buildSrc` using:
- **JaCoCo**: For generating standard coverage data (`.exec` files) and reports.
- **diff-cover**: A Python tool used to calculate coverage specifically on changed lines (diff coverage).

## Custom Plugin: `CodeCoveragePlugin`

The plugin is applied in the root `build.gradle.kts`:
```kotlin
apply<CodeCoveragePlugin>()

configure<CodeCoverageExtension> {
    excludes.addAll(
        listOf(
            "**/generated/**",
            "**/bin/main/**",
            "**/protobuf/**",
            "**/proto/**",
            "**/test/**"
        )
    )
}
```

### Key Tasks

#### 1. `jacocoRootReport`
- **Description**: Aggregates coverage data from all subprojects into a single report.
- **Output**: 
  - HTML: `build/reports/jacoco/jacocoRootReport/html/index.html`
  - XML: `build/reports/jacoco/jacocoRootReport/jacocoRootReport.xml`
  - CSV: `build/reports/jacoco/jacocoRootReport/jacocoRootReport.csv`
- **Configuration**: Automatically collects all `test.exec` files, source directories, and class files from subprojects that have the `java` or `java-library` plugin.

#### 2. `diffCoverage`
- **Description**: Reports coverage only on lines changed relative to a git branch.
- **Dependencies**: Depends on `jacocoRootReport` to ensure fresh coverage data is available.
- **Prerequisites**: Requires `diff-cover` to be installed on the system (`pip install diff-cover`).
- **Output**:
  - Markdown: `build/reports/diff-coverage.md`
  - HTML: `build/reports/diff-coverage-html/index.html`
- **Parameters**:
  - `diffCoverage.compareBranch`: The branch to compare against (default: `origin/main`).
  - `diffCoverage.failUnder`: Percentage threshold to fail the build if diff coverage is below it.

## Usage

### Generating Full Aggregate Report
To run all tests and generate the aggregate JaCoCo report:
```bash
./gradlew test jacocoRootReport
```

### Generating Diff Coverage Report
To see coverage for only your changes compared to `main`:
```bash
./gradlew diffCoverage
```

To compare against a different branch and enforce a coverage threshold:
```bash
./gradlew diffCoverage -PdiffCoverage.compareBranch=origin/develop -PdiffCoverage.failUnder=80
```

## Implementation Details (`buildSrc`)

- **`JacocoTasks.kt`**: Configures the standard JaCoCo plugin for all projects and registers the `jacocoRootReport` task.
- **`DiffCoverageTask.kt`**: A custom Gradle task that wraps the `diff-cover` CLI tool.
- **`CoverageHelper.kt`**: Utility functions to traverse subprojects and collect source sets, class files, and execution data.
- **`CodeCoverageExtension.kt`**: Allows configuring exclusions for the coverage reports.

## Requirements

1. **Java 21**: Configured via toolchains in the root build file.
2. **Python & pip**: For installing `diff-cover`.
3. **diff-cover**:
   ```bash
   pip install diff-cover
   ```
   
## Tools Used

1. [jacoco](https://docs.gradle.org/current/userguide/jacoco_plugin.html) for java and kotlin code coverage
2. [diff-cover](https://pypi.org/project/diff-cover/) to get the coverage report for changed code using the output generated by the `jacoco` plugin
